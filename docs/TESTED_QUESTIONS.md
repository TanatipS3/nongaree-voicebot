## 3. ปฏิเสธอย่างถูกต้อง (นอกขอบเขตกรมสรรพากร)

ระบบตอบว่า "หนูตอบได้เฉพาะเรื่องภาษีและบริการของกรมสรรพากร…" ซึ่งถูกต้อง

- วันนี้อากาศเป็นยังไง
- ค่าจ้างขั้นต่ำปีนี้เท่าไหร่
- จดทะเบียนสมรสใช้เอกสารอะไร
- นายกรัฐมนตรีคนปัจจุบันคือใคร
- แนะนำร้านอาหารแถวพญาไทหน่อย
- ต่อพาสปอร์ตที่ไหน
- อยากซื้อคอนโดต้องทำยังไง
- ธนาคารไหนดอกเบี้ยดีที่สุด
