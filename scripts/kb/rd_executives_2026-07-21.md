# ผู้บริหารระดับสูง | กรมสรรพากร

## ภูมิหลังหน้าที่

หน้านี้แสดงรายชื่อผู้บริหารระดับสูงของกรมสรรพากร (The Revenue Department) สำนักงานใหญ่ อยู่ที่ 90 ซอยพหลโยธิน 7 ถนนพหลโยธิน แขวงพญาไท เขตพญาไท กรุงเทพฯ 10400

---

## รายชื่อผู้บริหารระดับสูง

### 1. นายสมศักดิ์ อนันทวัฒน์
- **ตำแหน่ง:** อธิบดีกรมสรรพากร
- **โทรศัพท์:** 0 2272 8261

### 2. นายเกรียงศักดิ์ ประสงค์สุกาญจน์
- **ตำแหน่ง:** ที่ปรึกษาด้านประสิทธิภาพ
- **โทรศัพท์:** 0 2272 9537

### 3. นางสาวภิญญู กำเนิดหล่ม
- **ตำแหน่ง:** ที่ปรึกษาด้านเทคโนโลยีสารสนเทศและการสื่อสาร
- **โทรศัพท์:** 0 2272 8973

### 4. นางสาวสลักจิต พงษ์ศิริจันทร์
- **ตำแหน่ง:** ที่ปรึกษาด้านยุทธศาสตร์การจัดเก็บภาษี (กลุ่มธุรกรรมทางการเงินการธนาคาร)
- **ประเภท:** นักวิเคราะห์นโยบายและแผนทรงคุณวุฒิ
- **โทรศัพท์:** 0 2272 8833

### 5. นางสาวจิตรา ณีศะนันท์
- **ตำแหน่ง:** ที่ปรึกษาด้านพัฒนาฐานภาษี
- **ประเภท:** นักวิเคราะห์นโยบายและแผนทรงคุณวุฒิ
- **โทรศัพท์:** 0 2272 9909

### 6. นายกฤดา กฤติยาโชติปกรณ์
- **ตำแหน่ง:** รองอธิบดีกรมสรรพากร (รักษาการในตำแหน่ง)
- **ที่ปรึกษาด้าน:** ยุทธศาสตร์การจัดเก็บภาษี (กลุ่มธุรกิจพลังงาน)
- **ประเภท:** นักวิเคราะห์นโยบายและแผนทรงคุณวุฒิ
- **โทรศัพท์:** 0 2272 9539, 0 2272 8971

### 7. นายภาณุวัฒน์ เหลืองวิไล
- **ตำแหน่ง:** รองอธิบดีกรมสรรพากร
- **โทรศัพท์:** 0 2272 8274, 0 2272 9905

### 8. นายสุรยุทธ กอบกิจพานิชผล
- **ตำแหน่ง:** รองอธิบดีกรมสรรพากร
- **โทรศัพท์:** 0 2272 8633

### 9. นางสาวขวัญรัก สุวรรณรัมภา
- **ตำแหน่ง:** รองอธิบดีกรมสรรพากร
- **โทรศัพท์:** 0 2272 8975
