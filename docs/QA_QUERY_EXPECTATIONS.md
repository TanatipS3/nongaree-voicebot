# ความคาดหวังสำหรับชุดคำถาม QA

ใช้เอกสารนี้เป็น checklist สำหรับรีวิวบอตกับคำถามหลายประเภท เช่น FAQ ง่าย ๆ, การคำนวณภาษี, ค่าลดหย่อน, สถานการณ์จำลอง และคำถามที่ต้องอาศัย RAG จากเอกสาร

บอตมี 2 เส้นทางคำตอบ:

- **คำตอบเสียงพูด**: สรุปสั้นสำหรับให้บอตพูด
- **Detailed preview**: คำตอบแบบอ่านบนหน้าจอ มีโครงสร้างมากกว่า เช่น section, ตาราง, card และ marker

Marker ที่อาจเห็น:

```text
ANSWER
INFO
TABLE
CALC
FILING
DEDUCTION
CONDITION
```

## คำถามพื้นฐาน

| คำถาม | คำตอบที่คาดหวัง | Detailed preview ที่คาดหวัง |
|---|---|---|
| ภาษีคืออะไร? | อธิบายความหมายของภาษีแบบเข้าใจง่าย และเหตุผลที่รัฐจัดเก็บภาษี | `INFO` หรือ `ANSWER`; รูปแบบนิยามกระชับ ไม่ใช่ย่อหน้ายาว |
| ทำไมเราต้องเสียภาษี? | อธิบายว่าภาษีใช้สนับสนุนบริการสาธารณะ เช่น ถนน โรงพยาบาล โรงเรียน และบริการรัฐ | `ANSWER`; ควรเป็น bullet หรือ section สั้น ๆ อ่านง่าย |
| ใครบ้างที่ต้องยื่นภาษี? | อธิบายกลุ่มที่อาจต้องยื่น เช่น ผู้มีเงินได้ พนักงานประจำ ฟรีแลนซ์ เจ้าของกิจการ พร้อม caveat เรื่องประเภทและจำนวนเงินได้ | `TABLE` หรือรายการแบบมีโครงสร้าง; ควรบอกว่าการยื่นขึ้นกับประเภทและจำนวนเงินได้ |
| ยื่นภาษีได้ช่วงไหนของปี? | อธิบายช่วงเวลายื่นภาษีประจำปี และ caveat เรื่อง e-Filing | `FILING`; ควรแสดงช่วงเวลา/วันที่ชัดเจน |
| ถ้าลืมยื่นภาษีจะเกิดอะไรขึ้น? | อธิบายผลของการยื่นล่าช้า เช่น ค่าปรับ เงินเพิ่ม และสิ่งที่ควรทำต่อ | `FILING`, `CONDITION`; ควรมีขั้นตอนดำเนินการต่อ |

## รายได้เงินเดือน

| คำถาม | คำตอบที่คาดหวัง | Detailed preview ที่คาดหวัง |
|---|---|---|
| ฉันได้เงินเดือน 25,000 บาท ต้องเสียภาษีหรือไม่? | คำนวณรายได้ต่อปี บอกแนวโน้มว่าต้องยื่นหรือไม่ และมีภาษีต้องชำระหรือไม่ | `CALC`, `FILING`, `DEDUCTION`; มีตารางคำนวณรายได้ทั้งปี ค่าใช้จ่าย ค่าลดหย่อนส่วนตัว เงินได้สุทธิ เกณฑ์ที่เกี่ยวข้อง และคำถามต่อ |
| เงินเดือน 50,000 บาทต่อเดือน ต้องเสียภาษีเท่าไร? | ประมาณรายได้ต่อปีและภาษีเบื้องต้นหลังหักค่าใช้จ่าย/ลดหย่อนพื้นฐาน | `CALC`; ควรมีตารางคำนวณและสมมติฐาน/ช่วงอัตราภาษี |
| บริษัทหักภาษี ณ ที่จ่ายแล้ว ยังต้องยื่นภาษีอีกไหม? | อธิบายว่าภาษีหัก ณ ที่จ่ายไม่เท่ากับการยื่นภาษีประจำปี | `FILING`; ควรอธิบายการสรุปภาษีประจำปี การขอคืน หรือการจ่ายเพิ่ม |
| โบนัสต้องนำมาคำนวณภาษีหรือไม่? | อธิบายว่าโบนัสเป็นเงินได้จากการจ้างแรงงานและต้องรวมในรายได้ทั้งปี | `CALC` หรือ `CONDITION`; ควรบอกว่าโบนัสอาจมีผลต่อฐานภาษีและการหัก ณ ที่จ่าย |

## ฟรีแลนซ์ / ขายของออนไลน์

| คำถาม | คำตอบที่คาดหวัง | Detailed preview ที่คาดหวัง |
|---|---|---|
| รับงานฟรีแลนซ์ปีละ 300,000 บาท ต้องยื่นภาษีไหม? | อธิบายว่ารายได้ฟรีแลนซ์โดยทั่วไปต้องยื่น พร้อมสมมติฐานเรื่องค่าใช้จ่าย | `CALC`, `FILING`; ควรแสดงประเภทเงินได้ ค่าใช้จ่ายที่หักได้ แบบ/เกณฑ์การยื่น และคำถามต่อ |
| ขายของใน Shopee และ Lazada ต้องเสียภาษีหรือไม่? | อธิบายว่ารายได้จากการขายออนไลน์เป็นรายได้ที่อาจต้องเสียภาษีหากเป็นการประกอบธุรกิจ | `FILING`, `CONDITION`; ควรพูดถึงหลักฐานรายรับ รายงานจาก platform ต้นทุน และ caveat เรื่อง VAT หากรายได้สูง |
| รายได้จาก TikTok และ YouTube ต้องเสียภาษีอย่างไร? | อธิบายว่ารายได้ creator เป็นเงินได้ที่ต้องพิจารณาภาษี และอาจเกี่ยวกับ platform/ต่างประเทศ/หัก ณ ที่จ่าย | `FILING`, `CONDITION`; ควรถามต่อเรื่องผู้จ่าย ประเทศที่จ่าย ภาษีหัก ณ ที่จ่าย และรายได้รวมทั้งปี |
| รับเงินจากต่างประเทศต้องยื่นภาษีไหม? | อธิบายว่าขึ้นกับถิ่นที่อยู่ทางภาษี แหล่งที่มาของเงิน ระยะเวลานำเงินเข้าไทย และกฎภาษีไทย | `CONDITION`; ควรหลีกเลี่ยงคำตอบฟันธงเกินไป และถามข้อมูลเพิ่มเรื่อง residency/source/timing |

## ค่าลดหย่อน

| คำถาม | คำตอบที่คาดหวัง | Detailed preview ที่คาดหวัง |
|---|---|---|
| ประกันชีวิตลดหย่อนภาษีได้เท่าไร? | อธิบายวงเงินประกันชีวิต ประกันสุขภาพ และเงื่อนไขหลัก | `DEDUCTION`, `CONDITION`; ควรเป็น layout ค่าลดหย่อน: สรุป, ตารางวงเงิน, เงื่อนไข และ `ควรถามต่อ` |
| ดอกเบี้ยบ้านลดหย่อนภาษีได้หรือไม่? | อธิบายว่าดอกเบี้ยกู้ซื้อบ้านลดหย่อนได้ และมีวงเงินต่อปี | `DEDUCTION`, `CONDITION`; ควรมีวงเงิน เงื่อนไขสินเชื่อบ้าน และหลักฐานที่ต้องใช้ |
| บริจาคเงินให้โรงพยาบาลลดหย่อนภาษีได้ไหม? | อธิบายว่าขึ้นกับประเภทหน่วยรับบริจาคและหลักฐาน/e-Donation | `DEDUCTION`, `CONDITION`; ควรพูดถึงบริจาคทั่วไป/บริจาคพิเศษถ้ามีข้อมูล |
| กองทุน RMF และ SSF ลดหย่อนภาษีอย่างไร? | อธิบายแนวคิดวงเงินลดหย่อนของกองทุน RMF/SSF และเงื่อนไขถือครอง | `DEDUCTION`, `CONDITION`; ควรใช้ตารางเปรียบเทียบ RMF กับ SSF และบอกเงื่อนไขถือครอง |

## คำถามซับซ้อน

| คำถาม | คำตอบที่คาดหวัง | Detailed preview ที่คาดหวัง |
|---|---|---|

| มีรายได้จากการปล่อยเช่าคอนโด ต้องยื่นภาษีแบบไหน? | อธิบายการยื่นรายได้ค่าเช่าและทางเลือกการหักค่าใช้จ่าย | `FILING`, `CONDITION`; ควรพูดถึงประเภทเงินได้ค่าเช่าและหลักฐาน |
| หากมีรายได้จากต่างประเทศและในประเทศไทยพร้อมกัน ต้องเสียภาษีอย่างไร? | อธิบายว่าขึ้นกับ tax residency, แหล่งเงินได้, การนำเงินเข้าไทย และอาจมี treaty/foreign tax credit | `CONDITION`; ควรถามข้อมูลเพิ่มและหลีกเลี่ยงคำตอบแบบเหมารวม |
| กำไรจากการขายคริปโตต้องเสียภาษีหรือไม่? | อธิบายว่ากำไรจากคริปโตอาจเป็นเงินได้ที่ต้องเสียภาษี และต้องมีบันทึกธุรกรรม | `CONDITION`, `FILING`; ควรพูดถึงกำไร/ขาดทุน ภาษีหัก ณ ที่จ่ายถ้ามี และ transaction records |

## คำถาม RAG ยาก

คำถามกลุ่มนี้ควรอ้างอิงข้อมูลจากเอกสารที่ retrieve ได้ หาก context ไม่พอ ไม่ควรแต่งรายละเอียดเอง

| คำถาม | คำตอบที่คาดหวัง | Detailed preview ที่คาดหวัง |
|---|---|---|
| ระบบ TCL ของกรมสรรพากรมีหน้าที่อะไร? | อธิบายหน้าที่ของ TCL จากบริบทเอกสารภายใน/เอกสารที่ retrieve ได้ | `INFO` หรือ `TABLE`; ควรสะท้อนข้อมูลจาก retrieved context และหลีกเลี่ยงการเดาทั่วไป |
| หากระบบ TCL หยุดให้บริการ 1 วัน จะส่งผลกระทบต่อการจัดเก็บภาษีอย่างไร? | อธิบายผลกระทบเชิงปฏิบัติการจากเอกสาร หรือบอกว่าข้อมูลไม่พอถ้า context ไม่ชัด | `CONDITION`; ควรแยกข้อมูลที่รู้จากเอกสารกับสมมติฐาน |
| ขั้นตอนการคืนภาษีอากรตามเอกสารกรมสรรพากรมีอะไรบ้าง? | แสดงขั้นตอนการคืนภาษีจากเอกสารที่ retrieve ได้ | `TABLE` หรือขั้นตอนแบบมีโครงสร้าง; เสียงพูดควรสั้นถ้ารายการยาว |
| เอกสารใดบ้างที่ใช้ประกอบการขอคืนภาษีมูลค่าเพิ่ม? | แสดงรายการเอกสารประกอบการขอคืน VAT จาก RAG context | `TABLE`, `CONDITION`; ควรแสดงรายการเต็มใน detailed preview และไม่ควรอ่านรายการยาวทั้งหมดเป็นเสียง |

## Checklist สำหรับ Supervisor

ตรวจแต่ละคำถามตามหัวข้อต่อไปนี้:

- บอตพูดเป็นสรุปสั้น ไม่ใช่อ่าน detailed preview ทั้งหมด
- Detailed preview ไม่เป็น blob text เมื่อคำถามเป็นการคำนวณ ค่าลดหย่อน เงื่อนไขเยอะ หรือรายการยาว
- Marker ของ preview ตรงกับประเภทคำตอบ
- Detailed preview ไม่มีคำลงท้ายแบบเสียงพูด เช่น `ค่ะ` / `ครับ`
- คำตอบเงินเดือนมีสมมติฐานและคำถามต่อ
- คำตอบเงินเดือนพิจารณาอายุเมื่อผู้ใช้ระบุอายุ
- คำตอบค่าลดหย่อนมีวงเงิน เงื่อนไข และคำถามต่อเฉพาะทาง
- คำตอบ RAG ไม่ hallucinate เมื่อ retrieved context ไม่ชัดเจน
